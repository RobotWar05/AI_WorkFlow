# Full-stack quality gates

- G0: end-to-end journey, schema owner và deploy order rõ.
- G1: consumer/provider dùng cùng contract version.
- G2: auth, validation và error mapping đúng qua boundary.
- G3: migration giữ compatibility trong rollout window.
- G4: cross-layer tests và representative UI flow có evidence.
- G5: rollback khôi phục cả data/API/client behavior theo phạm vi đã phê duyệt.
