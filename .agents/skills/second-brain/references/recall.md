# Recall workflow

1. Translate the question into concepts, aliases, project names, dates, and likely paths.
2. Search titles and properties first, then linked notes and full text.
3. Prefer direct decisions and source notes over summaries.
4. Compare reviewed dates for claims that can drift.
5. Report conflicts, stale evidence, and missing context.
6. Answer concisely with clickable paths when the environment supports them.

Do not treat an old note as current system state without verification.
