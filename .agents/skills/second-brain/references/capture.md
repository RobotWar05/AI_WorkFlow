# Capture workflow

1. Extract only knowledge likely to remain useful beyond the current exchange.
2. Classify it as inbox, project, area, resource, atomic note, map of content, or system template.
3. Search for an existing authoritative note and conflicts.
4. Preserve source wording only when quotation is necessary and licensed; otherwise summarize.
5. Add provenance, observation date, confidence, and unresolved questions.
6. Propose the exact destination and change.
7. Wait for explicit approval.
8. Apply the smallest approved edit and verify links and properties.

Do not automatically promote a capture from inbox to durable knowledge.
