# Summarize a session

```text
Use $manage-project-context. Verify files, commands, exit codes and acceptance evidence from this session first.

If I approve saving the handoff: append only verified events to .agents/history/YYYY-MM-DD.md, update history/index.md only for a new date, rewrite .agents/context/current.md as a concise snapshot, and rewrite .agents/context/handoff.md as one copy-ready new-chat prompt.

Do not copy raw chat, secrets, credentials or transient logs. Separate verified facts, inference, unknowns, failed/inconclusive checks and exact next action.
```
