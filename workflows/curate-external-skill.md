# Curate External Skill

1. Record upstream URL, author, license, exact revision, and intended capability.
2. Read every instruction, script, hook, dependency, and installer in scope.
3. Reject hidden network activity, automatic mutation, excessive permissions, vague triggers, or unsupported runtime claims.
4. Compare the capability with the current catalog and document overlap.
5. Prefer a small adaptation over importing a broad bundle.
6. Register the source as `candidate` or `quarantined`.
7. Run static validation, trigger tests, and paired baseline tests before graduation.
8. Update only from a reviewed diff; never auto-update.
