# Session Handoff

Modes: `close`, `resume`, `transfer`.

Produce a concise artifact containing:

- Objective and current status.
- Verified decisions and their evidence.
- Files read, changed, created, or intentionally untouched.
- Commands run and their actual results.
- Assumptions, unknowns, risks, and blocked items.
- Exact next action and any approval still required.

Do not claim a file was written unless it exists. Do not copy secrets or unnecessary conversation history. Save only after the user approves the target path.
