# Single-agent delivery

1. Validate work item; giữ mode `single-owner`.
2. Đọc root map, một domain annex và skill tối thiểu.
3. Ghi plan ngắn cho task vừa/lớn; khóa acceptance trước khi viết.
4. Thực hiện trong write scope được cấp.
5. Tự review diff nhưng không coi self-reflection là bằng chứng.
6. Chạy verification plan; ghi command, exit code và meaningful output.
7. Tạo quality gate và handoff nếu chuyển phiên/người.
8. Chỉ đóng khi mọi acceptance pass hoặc phần inconclusive được nêu rõ.
