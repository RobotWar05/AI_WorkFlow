# Evaluation results

Commit only reviewed summaries. Put raw runtime transcripts in `evals/results/raw/`, which is ignored by Git unless a case must be preserved as evidence.

For each run record runtime, model, date, skill revision or tree hash, case IDs, baseline result, skill result, hard-guardrail violations, token/time measurements when available, reviewer, and conclusion. Do not mark a skill stable from this directory alone; update the registry only after the documented graduation gate is met.
