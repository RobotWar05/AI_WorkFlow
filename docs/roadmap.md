# Roadmap

## Đã có trong V2 Foundation

- Skill/profile/governance V1.
- Contract schemas và human forms.
- Task lifecycle, approval, ownership và failure policy.
- Role/topology canonical và ba adapter projection.
- Frontend, backend/API, full-stack và embedded annex.
- Static/negative/semantic validation.

## Cổng tiếp theo

1. Phê duyệt initial Git baseline và ghi tree hash.
2. Runtime smoke-test custom agents trên Codex và Antigravity.
3. Cài Claude Code nếu cần rồi kiểm tra adapter riêng.
4. Chạy cùng fixture bằng single-agent và manager-workers.
5. Thêm isolated-parallel chỉ sau stale-base/conflict/recovery tests.
6. Thử peer-team dưới feature flag, không làm dependency.
7. Graduate từng runtime khi hard guardrail đạt và outcome không kém baseline.

Framework-specific skill chỉ được thêm khi project thật xác nhận stack/version và eval chứng minh khoảng trống.
