# Project knowledge operations

This vault belongs only to this project. `current.md` and `history/` remain task-state data; this vault stores durable project knowledge.

Before any note write, show the target path, frontmatter, content or diff, affected links, provenance and conflicts. Wait for explicit approval.

Never store raw chat, credentials, API keys, private keys, recovery codes or unreviewed tool output. Keep source files in their original approved location unless the user explicitly approves a copy.
